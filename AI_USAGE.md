# AI Usage

## Tools Used

- Codex was used to scaffold and implement the full-stack assignment.

## Where AI Was Used

- Project structure planning
- Express API implementation
- PostgreSQL schema design
- React UI implementation
- Tailwind CSS and shadcn-style UI component setup
- Frontend TypeScript types
- README and setup documentation
- AI usage documentation

## Why AI Was Used

AI was used to accelerate repetitive setup work and provide a clean starting point for a small full-stack application. The final implementation remains intentionally simple so every file can be reviewed and understood.

## Example Prompts

- "Build this assignment in MERN."
- "Use TypeScript in the frontend, but keep backend files as JavaScript."
- "Add table display, create form, search, delete, loading states, error handling, and responsive UI."

## Generated Code Kept

- Express routing and controller structure
- PostgreSQL repository functions
- React component structure
- Form validation rules
- Docker Compose setup
- README setup instructions

## Generated Code Modified Or Rejected

- MongoDB was rejected because the assignment explicitly requires PostgreSQL.
- Backend TypeScript was replaced with JavaScript after the implementation requirement was clarified.
- A heavier NestJS setup was rejected in favor of Express to keep the implementation compact and easier to review.
- Complex deployment automation was not included because deployment account details were not available locally.
